🧹 Reset Machine

Xóa vĩnh viễn dữ liệu — giữ nguyên ứng dụng

Công cụ giúp xóa sạch mọi file cá nhân trên máy tính Windows theo kiểu không thể khôi phục, nhưng vẫn giữ lại:

  • ✅ Windows và hệ thống
  • ✅ Các ứng dụng đã cài + cấu hình của chúng
  • ✅ Toàn bộ thư mục (chỉ xóa file bên trong, giữ folder)
⚠️ Quan trọng: Đã xóa là KHÔNG thể lấy lại. Hãy đọc hết hướng dẫn và luôn bấm Quét để xem trước.

1 Mở ứng dụng

  • Vàoozovn-public/Du lieu loi thoi
  • Bấm chuột phải vào Reset-Machine-GUI.exe copy và dán vào Desktop cá nhân
  • Bấm chuột phải vào Reset-Machine-GUI.exe
  • Chọn Run as administrator → bấm Yes
Nếu Windows hiện cảnh báo SmartScreen: bấm More info → Run anyway.

2 Bấm "Quét" để xem sẽ xóa gì

Bấm nút 1. Quét — ứng dụng liệt kê mọi mục sẽ bị xóa, kèm số file và dung lượng.

DownloadsC:\Users\...\Downloads157 file · 5 GB
DocumentsC:\Users\...\Documents0 file · 0 B
Git (ứng dụng — nên bỏ tick)7430 file · 415 MB
💡 Mỗi dòng là 1 thư mục. Ứng dụng chỉ xóa file bên trong, giữ lại thư mục.

3 Bỏ tick những gì muốn giữ

Mặc định mọi mục đều được tick (sẽ xóa). Hãy bỏ tick những mục muốn giữ lại:

  • Phần mềm / công cụ (Git, VS Code, phần mềm kế toán…)
  • Dữ liệu quan trọng cần giữ
⚠️ Với ứng dụng: xóa file bên trong = hỏng app. Muốn giữ app thì phải bỏ tick.

4 Xóa

  • Bấm nút đỏ 2. XÓA VĨNH VIỄN
  • Gõ đúng chữ ERASE rồi bấm OK để xác nhận
  • Chờ chạy xong (có thanh tiến trình + nhật ký)
Hoàn tất xóa là đã xong. Nếu báo cần khởi động lại → restart máy để xóa nốt các file đang bị khóa.

❓ Lưu ý

  • 🔁 Không thể hoàn tác — luôn Quét và xem kỹ trước khi xóa.
  • 🔒 Mức độ không khôi phục: ổ HDD tuyệt đối; ổ SSD an toàn với phần mềm khôi phục thông thường, chuyên dụng
  • 📄 Kết quả: mọi file bị xóa vĩnh viễn, mọi thư mục vẫn còn (rỗng), ứng dụng được giữ nguyên.
